连接帮助 / HOW TO CONNECT

情况一：两台设备都用本页面（同一WiFi）

1. 双方都打开本页面（确保URL相同）
2. 各自在下方"局域网设备"列表看到对方
3. 点击对方旁边的 [连接] 按钮
4. 等待状态变为绿色"已连接"

情况二：BroadcastChannel 不可用时

1. 下方选择 [方法二: 手动密钥交换]
2. 发起方点"生成邀请密钥"→ 复制密钥 → 通过微信/QQ发送
3. 接收方粘贴密钥 → 点"确认并连接"
4. 发起方收到应答密钥后粘贴 → 完成连接

提示: 页面显示"未连接"是正常初始状态，必须完成上述步骤才会变绿。
